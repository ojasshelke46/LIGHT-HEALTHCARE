  <behavior>
    - `isHttpUrl("https://x/y")` -> true; `isHttpUrl("scans/a.pdf")` -> false.
    - `resolveResultUrl("https://x/y.pdf", signer)` -> returns the URL unchanged, signer NOT called.
    - `resolveResultUrl("scans/a.pdf", signer)` -> calls `signer("scans/a.pdf")` and returns its result.
    - `resolveResultUrl(null, signer)` -> null.
    - a signer that throws / returns null -> resolver returns null (caller toasts).
  </behavior>
  <action>
**apps/mobile/lib/reportUrl.ts** — PURE (no supabase/RN import), dependency-injected so vitest runs it in node:
  ```ts
  const HTTP_URL_RE = /^https?:\/\//i;
  export function isHttpUrl(s: string): boolean { return HTTP_URL_RE.test(s); }

  // signer resolves a Storage path -> signed URL (injected so this file stays pure)
  export async function resolveResultUrl(
    pathOrUrl: string | null,
    signer: (path: string) => Promise<string | null>,
  ): Promise<string | null> {
    if (!pathOrUrl) return null;
    if (isHttpUrl(pathOrUrl)) return pathOrUrl;
    try { return await signer(pathOrUrl); } catch { return null; }
  }
  ```
  This mirrors apps/web/src/lib/results.ts (http passthrough, else sign). The actual `storage.createSignedUrl(path, 3600)` call is the signer passed in by the Task-3 caller — keeping this module pure and node-testable.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-08 | I (Info disclosure) | reports.tsx nested visits/orders/prescriptions select | mitigate | Reads rely on the DEPLOYED patient_select RLS (scope `current_patient_id()`); the nested PostgREST embed inherits row-level scope, so no other patient's visit/order/prescription can be fetched. No service role in the app. |
| T-04-09 | I (Info disclosure) | ReportVisitGroup createSignedUrl | mitigate | Signed URLs are TTL 3600s, generated per-tap, never cached; the path comes only from an RLS-scoped `orders.result_url` the patient already owns, so a patient cannot sign a path they cannot read. |
| T-04-10 | T (Tampering) | ReportVisitGroup Linking.openURL | mitigate | `Linking.openURL` only receives resolver output; the scheme is validated as `http(s)` before opening, preventing arbitrary-scheme deep-link abuse from a malformed stored value. |
</threat_model>
