## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → medicines writes | Inline stock edit + add-medicine insert cross into the medicines table |
| URL query params → server query | dispensed from/to reach a PostgREST filter builder |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-13 | Elevation of Privilege | medicines inline edit + insert | mitigate | Writes go through the anon client under the deployed pharmacist-only RLS (medicines_pharmacist_all); no other role can tamper; no service role in browser |
| T-03-14 | Tampering | inventory inputs | mitigate | Inline stock parsed as int ≥ 0 (invalid ignored); add-medicine zod-validated (name required, int stock/threshold ≥ 0, price ≥ 0 max 2dp) before insert |
| T-03-15 | Injection | dispensed date filter | mitigate | from/to pass only through istRangeFromDates (Date math, NaN-safe); no raw string interpolation into filters; RLS-scoped to pharmacist |
</threat_model>
