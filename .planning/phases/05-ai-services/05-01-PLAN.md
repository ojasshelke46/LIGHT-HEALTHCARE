# Plan 05-01 — FastAPI AI services (typed mocks + production Dockerfile)

<objective>
Ship apps/ai-services: FastAPI app with /health, CORS, and three typed mock endpoints matching the brief's contracts exactly, plus a production Dockerfile. All four AI-01..04 requirements in one vertical slice.
</objective>

<threat_model>
- T-05-01 (input abuse): Pydantic models constrain all inputs (types, enums, ge/le bounds on age); FastAPI returns 422 on violations. Mitigated.
- T-05-02 (info leakage): exception handler returns generic 500 detail, never tracebacks. Mitigated.
- T-05-03 (CORS): origins from CORS_ORIGINS env (comma-separated), defaulting to http://localhost:3000 only — no wildcard in code. Mitigated.
- T-05-04 (container): non-root user in Dockerfile; slim base; no secrets baked in (.env.example only). Mitigated.
- T-05-05 (SSRF via audio_url): scribe endpoint does NOT fetch audio_url in mock mode — validated as HttpUrl, echoed only. Note for V2 real implementation. Accepted for v1.
</threat_model>

<read_first>

- apps/ai-services/README.md (placeholder to replace)

<action>
Create:

1. `apps/ai-services/requirements.txt` (brief-mandated): fastapi, uvicorn[standard], celery, redis, python-dotenv, openai, httpx, pydantic — unpinned-major style (e.g. `fastapi>=0.115`), one per line.

2. `apps/ai-services/main.py`: `create_app()` factory + module-level `app`. Loads dotenv. CORS middleware with origins from `CORS_ORIGINS` env (comma-separated; default `http://localhost:3000`). `GET /health` → `{"status": "ok", "service": "ai-services"}`. Mounts the three routers under `/api`. Global exception handler: unhandled → JSON 500 `{"detail": "Internal server error"}` (no traceback leakage).

3. `apps/ai-services/services/__init__.py` (empty) and three routers:

`services/symptom_triage.py` — POST `/triage`:
- Request: `TriageRequest(symptoms: str [min_length=1], patient_age: int [ge=0, le=120], patient_gender: str)`
- Response: `TriageResponse(suggested_department: str, urgency: Literal["low","medium","high","emergency"], reasoning: str)`
- Mock: keyword map — chest pain/breathless → Cardiology+emergency; fever/cough/cold → General Medicine+low; headache/dizzy → Neurology+medium; fracture/joint/bone → Orthopedics+medium; child age<12 boosts to Pediatrics; default General Medicine+low. Reasoning string names the matched keyword(s).

`services/drug_interaction.py` — POST `/drug-check`:
- Request: `DrugCheckRequest(current_medicines: list[str], new_medicine: str [min_length=1])`
- Response: `DrugCheckResponse(safe: bool, interactions: list[Interaction])`, `Interaction(drug_pair: str, severity: str, description: str)`
- Mock: case-insensitive known-pairs table with ≥4 real-ish pairs (warfarin+aspirin severe bleeding risk; ibuprofen+aspirin moderate GI; metformin+alcohol moderate lactic acidosis; azithromycin+amlodipine minor QT). safe = no matches.

`services/scribe.py` — POST `/scribe`:
- Request: `ScribeRequest(audio_url: HttpUrl)` — NOT fetched (T-05-05)
- Response: `ScribeResponse(chief_complaint: str, diagnosis: str, notes: str, structured_soap: SOAP)`, `SOAP(subjective, objective, assessment, plan: str)`
- Mock: deterministic canned consult note that references the audio filename from the URL path.

All models Pydantic v2 style. No `Any` types.
