Create `apps/web/src/lib/hooks/use-realtime.ts` (`"use client"`). Implement per D-15/D-16:

```typescript
export interface RealtimeListResult<T> {
  data: T[];
  loading: boolean;
  error: string | null;
  refetch: () => void;
  connected: boolean;
}

export function useRealtimeList<T>(
  fetcher: () => Promise<{ data: T[] | null; error: { message: string } | null }>,
  tables: string[],
): RealtimeListResult<T>
```

Implementation notes:
- Hold `fetcher` in a ref (`fetcherRef`) updated every render so the subscription effect does NOT re-run when the caller passes a new inline fetcher; the effect depends only on `tables.join(",")`.
- `runFetch()`: call `fetcherRef.current()`, on `{ data }` set data (`?? []`) and clear error; on `{ error }` set `error` to `error.message` and keep prior data. Always clear loading.
- Debounced refetch: a `debouncedRefetch()` that clears+sets a 300ms timeout calling `runFetch()`.
- Subscribe: `const channel = supabase.channel('realtime-' + tables.join('-'))`; for each table `channel.on('postgres_changes', { event: '*', schema: 'public', table }, debouncedRefetch)`; then `channel.subscribe((status) => { ... })`.
  - status 'SUBSCRIBED' → setConnected(true), reset backoff to 1000, and runFetch() (resubscribe refetch).
  - status 'CHANNEL_ERROR' | 'TIMED_OUT' | 'CLOSED' → setConnected(false), `supabase.removeChannel(channel)`, schedule `reconnect()` after current backoff, then `backoff = Math.min(backoff * 2, 30000)`.
- `visibilitychange` listener: when `document.visibilityState === 'visible'` call `runFetch()`.
- Initial `runFetch()` on mount (loading starts true).
- Cleanup on unmount: clear debounce + reconnect timers, `supabase.removeChannel(channel)`, remove visibility listener.
- Never use `any`; keep the generic `T`. Reuse the existing `createClient()` from `@/lib/supabase/client` (create the client once via `useState(() => createClient())` or a ref).

```typescript
export function ageFromDob(dob: string | null): number | null {
  if (!dob) return null;
  const b = new Date(dob);
  if (Number.isNaN(b.getTime())) return null;
  const now = new Date();
  let age = now.getFullYear() - b.getFullYear();
  const m = now.getMonth() - b.getMonth();
  if (m < 0 || (m === 0 && now.getDate() < b.getDate())) age--;
  return age;
}
```

```typescript
export function todayISTRange(): { startISO: string; endISO: string } {
  const OFFSET = 5.5 * 60 * 60 * 1000;
  const ist = new Date(Date.now() + OFFSET);
  const startUTC = new Date(Date.UTC(ist.getUTCFullYear(), ist.getUTCMonth(), ist.getUTCDate()) - OFFSET);
  const endUTC = new Date(startUTC.getTime() + 24 * 60 * 60 * 1000);
  return { startISO: startUTC.toISOString(), endISO: endUTC.toISOString() };
}
```
