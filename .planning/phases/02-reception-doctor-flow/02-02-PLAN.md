## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Elevation of privilege | appointments.update (check-in/no-show) | mitigate | Write goes through the RLS-scoped anon client; if the update returns an RLS/permission error, STOP and surface it as a checkpoint (do NOT switch to service-role or work around) |
| T-02-05 | Tampering | optimistic status flip | mitigate | Optimistic value is local only; the authoritative status comes from the RLS-scoped realtime refetch, and a failed write rolls back the local value |
| T-02-06 | Information disclosure | patient name/phone on board | accept | Reception is authorized to see today's queue PII by role; no export path, no cross-role exposure (middleware blocks other roles) |
</threat_model>
