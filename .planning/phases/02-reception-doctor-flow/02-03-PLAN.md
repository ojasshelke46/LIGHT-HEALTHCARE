1. **Create `apps/web/src/lib/search.ts`** — injection mitigation for PostgREST `.or()` filters:
```typescript
/** Strip characters that have meaning in PostgREST filter syntax so user
 *  input cannot break out of an ilike pattern or inject extra OR conditions. */
export function sanitizeSearchTerm(raw: string): string {
  return raw.replace(/[,()*%\\]/g, "").trim().slice(0, 40);
}
```

2. **Create `apps/web/src/app/reception/patients/page.tsx`** — thin `"use client"` page rendering `<PatientsClient />`. Create `apps/web/src/app/reception/patients/patients-client.tsx` (`"use client"`):
