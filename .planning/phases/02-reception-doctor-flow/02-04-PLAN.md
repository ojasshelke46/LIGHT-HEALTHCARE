Billing query (D-25) — today's completed visits LEFT JOIN payments + orders count:
```typescript
const { startISO, endISO } = todayISTRange();
supabase.from("visits")
  .select("id, diagnosis, completed_at, patient_id, patients(name, phone), orders(id), payments(id, amount, method, status)")
  .not("completed_at", "is", null)
  .gte("completed_at", startISO).lt("completed_at", endISO)
  .order("completed_at", { ascending: false });
```
