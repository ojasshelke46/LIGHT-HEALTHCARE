<objective>
Establish the async-state conventions that every later phase inherits (SHELL-02):
a shared page-shaped loading skeleton, a client error boundary with retry, and a
reusable empty state — wired as per-portal `loading.tsx`/`error.tsx` (D-12) — and
complete the hand-rolled primitive library (tabs, textarea, select, table) that D-01
scopes to this phase as the Phase-2 form contract.

Purpose: Locks the loading/error/empty pattern so Phase 2-3 realtime views drop into
a known shape instead of inventing their own; finishes the primitive set so later
forms don't block on missing components.

Output: `empty-state.tsx`, `portal-loading.tsx`, `portal-error.tsx`, ten per-portal
route files, and `ui/{tabs,textarea,select,table}.tsx`.
</objective>
